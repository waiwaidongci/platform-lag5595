# 地铁站台通风噪声滞后排查

对齐声级和风机频率，核对噪声变化与调速之间相隔多久。

澄湾轨道交通机电组，三班轮值，负责 6 座车站的通风设备和站台声环境巡检。 站务把声级计与楼控系统的风机频率导出到同一时间轴，机电值班员复核接报时段。系统逐个滞后计算相关系数和配对数，并标明缺测时段。复核员据此圈定现场复测窗口，交接时附上站台、风机编号及原始数据的时间范围。

- 手工移动表格行时，时钟错位或中间跳采容易被误当成真实滞后。
- 只看相关系数最高的一档，容易漏掉该档实际只有很少的配对。
- 交班记录里只有峰值截图，接班人难以定位采集断点和该复看的设备。

## 业务模块

| 模块 | 用途 |
|---|---|
| 站台排查总览 | 查阅业务口径、当班流程及最新运行。主管可以核对审计记录。 |
| 声级与风机明细 | 下载「澄湾站_TVF-02_20261121.csv」并核对字段。分析员可导入 UTF-8 CSV，保留数据指纹和原始行。 |
| 滞后扫描 | 选择批次和参数并提交后台计算，可从运行列表追踪状态。 |
| 相关峰与缺测 | 查看业务指标、证据表和解释，通过来源链接回查数据。 |
| 机电复核 | 查看待处理或已完成记录。复核主管可提交机电复核意见及依据。 |
| 交班与导出 | 按批查找结果，核对复核状态并下载相应的 CSV。 |

## 演示流程

1. 11 月 21 日 10:00 导出澄湾站下行站台的声级计和 TVF-02 风机记录。
2. 以站内本地时间合并成「澄湾站_TVF-02_20261121.csv」，保留空白读数和断采时间。
3. 在「声级与风机明细」导入样例，核对 09:30:00 至 09:44:50 的观测窗口。
4. 在「滞后扫描」设定 10 秒采样间隔、左右各扫描 12 格，每档至少 30 对。
5. 在「相关峰与缺测」查看 +3 格附近的相关峰，核对完整配对数和 09:41:10 起的双路断采。
6. 在「机电复核」记录风机调档和列车进出站时间，安排同站台复测。
7. 在「交班与导出」下载扫描明细，向下一班交接 TVF-02 和待补的遥测时段。

## 计算口径

- 一批只含一个站台和一台风机。以最早时间戳为网格起点，使用指定的固定秒间隔，重复时间戳或离网格记录须修正。
- 滞后 k 配对风机 F(t) 和声级 S(t+kΔ)。正滞后表示声级变化晚于风机，负滞后表示声级变化早于风机。
- 每档对完整配对分别中心化，Pearson r 为配对离均差乘积之和除以两列离均差平方和的几何平均。样本不足或任一序列恒定时不计算 r。
- 空白和未采集的时间格均视为缺测，不作填补。配对缺口以该滞后在观测窗口内理论可配对的格数为分母。
- 按 |r| 选择候选峰。相近值按 12 位小数比较，再依次选配对数较多、绝对滞后较小、滞后值较小的档位。结果用于定位复测时段，因果判断仍需现场验证。

## 本地开发

| 组件 | 实现 |
|---|---|
| 前端 | Nginx 与原生 HTML、CSS、JavaScript。`frontend/src/pages` 放页面，`components/common` 放共用表格、图表及表单。 |
| API | Python 3.11、FastAPI、SQLAlchemy。`backend/src/domain` 放本项目字段、业务计算和演示数据，`routes` 放接口，`models` 放表模型。 |
| 后台 | 独立 Python worker，通过 Redis 唤醒，从数据库租约领取计算，CSV 写入共享卷。 |
| 数据 | MySQL 8 存储批次、运行与审计。`backend/scripts/seed_demo.py` 可安全重复执行。 |

改动前端后执行 `docker compose up -d --build frontend`。改动接口或算法后执行 `docker compose up -d --build backend worker`，再刷新浏览器。如需保留数据，停止时执行 `docker compose down`。使用 `docker compose down -v --remove-orphans` 会清除该项目的数据库、Redis 和报表卷。

`.env.example` 中的 `COMPOSE_PROJECT_NAME`、`FRONTEND_PORT`、`BACKEND_PORT`、`DB_PORT`、`APP_SUBNET` 控制项目隔离。`DB_PASSWORD`、`JWT_SECRET` 和 `SEED_DEMO` 为本机演示默认设置。后端 `constants/enums.py` 与前端 `src/constants/enums.js` 保持角色、运行状态和复核状态一致。项目许可证见 `LICENSE`。
