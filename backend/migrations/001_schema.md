# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束。现有数据表只补建缺失表，升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `datasets` 不可变记录批次，以名称和 SHA-256 去重。
- `time_syncs` 批次首尾对时记录（`dataset_id`+`endpoint` 唯一），带 `version` 乐观锁支持并发更正。
- `runs` 记录参数、数据批次、运行租约、分析结果、导出文件及复核决定。排队时对时快照写入 `params.clock_sync`，重试不更换。
- `schedules` 保存定时计划和下一到期时间。
- `deliveries` 保存站内分发回执，每次运行最多一个回执。
- `audit_events` 记录登录、数据入库、对时更正、运行、复核和报表分发动作。
